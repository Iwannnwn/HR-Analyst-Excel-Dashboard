
# RECRUITMENT APPLICATION ANALYTICS DASHBOARD | Microsoft Excel

Developed an interactive Excel dashboard to analyze recruitment application data using a synthetic recruitment dataset. Explored applicant distribution across departments, job positions, work locations, gender, job levels, and employment types. Utilized Pivot Tables, Pivot Charts, and Slicers to transform raw data into meaningful insights, track key recruitment metrics, and enable interactive data exploration.
